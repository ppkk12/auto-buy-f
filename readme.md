# Fortnite Shop Free Claimer

Web版アイテムショップ（`fortnite.com/item-shop`）で、0 V-Bucks になっている未所持アイテムをまとめて取得する Chrome 拡張です。

## 導入手順
1. `chrome://extensions` を開いて右上の「デベロッパー モード」を有効化
2. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選択
3. コードを変更した場合は拡張機能をリロードし、ショップのページを `Ctrl + Shift + R` で再読み込み

## 使い方
1. Epic Games にログインした状態でアイテムショップを開く（右下にパネルが表示されます）
2. 「検出数」に対象アイテム（未所持・V-Bucks表記・0 V-Bucks）の件数が出るのを確認
3. 「取得開始」をクリック（「実行前に一覧を確認」にチェックが入っている場合は、対象リストを確認してもう一度クリック）
4. 最初の1件で疎通確認を行い、通ったら残りを並列送信します。途中で止める場合は「停止」を押してください

## 仕様メモ
- ページ内の React Router ストリームデータからカタログ情報（`offerId` / `pricing.finalPrice` / `currencyType` / `ownershipStatus`）を抽出しています。
- 購入処理は `/item-shop/purchase.data` への POST です。実行時に `/item-shop/resources/csrf-token.data` から CSRF トークンを取得して送信します。手動で0円アイテムを取得した通信が検知された場合は、そちらのリクエスト形式をそのまま流用します。
- 誤購入防止のため、現金決済枠・ギフト・所持済み・価格が0以外のデータは対象から外し、送信直前にも価格パラメータを `0` に固定しています。
- 429（レート制限）が返った場合は自動で待機時間を入れ、並列数を落とします。

## トラブルシュート
うまく取得できない場合は、パネル下部の「ログをコピー」から通信履歴をクリップボードにコピーしてステータスコードを確認してください（トークン等は自動でマスクされます）。
